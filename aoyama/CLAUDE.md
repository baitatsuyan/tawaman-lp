# タワマン大家 個別相談 LP（青山綜合地所）

日本のお客様向けの静的LP。HTML＋CSS＋素のJSのみ、ビルド不要。構成と公開前の作業は README.md を参照。
公開URL: https://tawamanoya-aoyama.netlify.app/ （Netlify の Base directory = `aoyama`、`site/` を配信）

**リポジトリ直下の LP（Miyama & Jung Partners 版）とは別会社の、独立したLP。** ファイルを共有しない（CSS・JS・画像もこのフォルダ内のコピーを使う）。直下の CLAUDE.md のルールはここには適用しない。片方を直しても、もう片方に合わせる必要はない。

## 変更するときのルール

- 公開されるのは `site/` だけ。公開しないもの（スクリプト・メモ）は `site/` の外に置く。
- Miyama & Jung Partners の名前・リンク・YouTube 動画（同社のコンテンツ）は載せない。韓国語ページは作らない。
- 宅建業者は株式会社青山綜合地所（東京都知事（3）第99195号）。体制は「青山綜合地所が提供し、同社から業務委託を受けたタワマン大家が担当」。
- 特典は LINE公式アカウント「BAI Capital」の友だち追加で渡す。PDF をこのサイトに置かない。
- **フォームの選択肢の `value` は Google フォームの選択肢と一致させる。** 一致していないと回答が黙って捨てられる。設問は `tools/setup-google-form.gs`、entry ID は `site/assets/form.js` の `ENTRY`。
- 「数字で確かめる」欄の試算と坪単価グラフは、「目安」「過去の集計」であることと、収益・融資の可否を約束しない旨の注記を消さない。グラフの出典・免責文は不動産情報ライブラリの利用約款で必要。
- 料金・解約・仲介手数料の記載を変えるときは、LPのプラン欄と `site/tokushoho/index.html` を必ず一致させる。

## 表現の方針

- エリアを限定しない（「湾岸」「23区」と書かない）。坪単価グラフだけは勝どき・晴海・豊洲・有明を地区名で出す。
- 報酬の分配（仲介手数料の一部を受け取ること）は書かない。「紹介料・広告費を受け取らない」とも書かない。
- 融資は「助言」にとどめる。「持ち込み」「代わりに申し込む」と読める表現は使わない。申込みはご本人から行う旨を残す。
- 「買う人の目線で」。断定表現（「値上がりが見込める」「下がらない」「必ず」など）を避ける。
- 税務は「税額の計算や申告など個別の判断は税理士にご確認ください」とする（青山綜合地所の税理士体制が確認できるまで）。

## デザイン

- CSS は `site/assets/style.css` 1枚。ブレークポイントは `max-width: 1000px` の1か所。
- 本文は両端揃え、見出しは `word-break: auto-phrase`。
- 横に並ぶカードは subgrid で行位置をそろえている。カードの要素数を変えるときは `grid-row: span N` も合わせる。
- 変更後は PC 幅（1440px）とスマホ幅（375px）の両方で崩れていないか確認する。
